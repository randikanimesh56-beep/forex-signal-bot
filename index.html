Important limitations
• Signals are technical-rule outputs, not predictions or guarantees of profit.
• The selected timeframe is a candle interval, not the 5-second refresh rate. This provider supports 1-minute and longer candle intervals; 5S/15S/30S candles are not offered by this endpoint.
• The free plan has API quotas. This page fetches market candles no more than once per minute to avoid wasting requests; the dashboard itself refreshes every 5 seconds.
• For privacy, the API key is entered in this browser page and is not sent to a server run by this app. But any key used in a public static website can be inspected by the browser, so use a restricted/low-quota key and do not reuse a sensitive key.
